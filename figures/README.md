# Generated figures

Running `Rscript run_all.R` creates:

- `home_advantage_by_period.png` — headline posterior median and 95% interval plot
- `period_contrasts.png` — posterior distributions of the three period contrasts
- `rhat_ess.png` — convergence diagnostic summary
- `trace_plot.png` — MCMC trace plots
- `posterior_predictive_check.png` — observed versus replicated outcome rates
- `ghost_home_advantage_by_phase.png` — pre/early ghost/later ghost/post comparison
- `ghost_home_advantage_over_time.png` — continuous trend across ghost games
- `ghost_dynamics_trace.png` — convergence check for the early/later extension

The repository includes the key figures generated from the validated model run. Rerunning the pipeline replaces them with figures from the newly fitted models.
